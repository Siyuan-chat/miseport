## 動画B — 自分の店を接続する実演（将来の正式リリース用 3〜5分）

**今は公開用に作らない。** 自動API連携・CSVフォールバック・公開手順を実装し、非技術者の受入テストを通過してから、本物のテストショップとダミー商品で収録する。

| セクション | 見せる画面（実装後） | 伝えること |
|---|---|---|
| 1. 準備 | MisePortの日本語スタート画面、対応プラットフォーム一覧 | 「商品CSV・公式API・自分のAgentのどれかを選べる」 |
| 2. 認可 | BASE読み取り用PATまたは承認済みOAuth画面。**トークンを表示しない** | 「読み取りだけを許可。顧客・注文の権限は不要」 |
| 3. 接続確認 | 接続成功、対象ショップ、最終取得時刻 | 「自分の店の商品だけを読む」 |
| 4. 商品一覧 | 公開商品、SKU・バリエーション、チェック結果の一覧 | 「価格・送料・在庫の不明を明確にする」 |
| 5. 確認と修正 | データを商店自身が確認。未公開を除外、警告を説明 | 「AIが事実を自動で作らない」 |
| 6. 成果物 | JSON / JSON-LD / 各社検証済みCSVを選択 | 「互換性と出典を保ち、必要な形式でダウンロード」 |
| 7. 公開（任意） | 商店所有のホストで公開、実際のURLを取得 | 「MCP公開には外部サービスの条件・アカウントが必要な場合あり」 |
| 8. 再同期・停止 | 再取得、古いデータ警告、認可解除 | 「自分でコントロール、必要に応じて停止」 |

**撮影しないこと:** 本物のトークン、ショップの売上、顧客・注文情報、他人の管理画面、認証回避、未完成のクリック動作。プラットフォーム画面の利用には権利と利用条件の確認を行う。架空データを本当の商店取扱商品として語らない。

## 動画C — プラットフォーム別接続の短編（各1〜3分・将来）

BASE PAT、Shopify正式アプリ承認、makeshop管理者向け設定、カラーミーOAuth、EC-CUBEプラグイン接続の**実装済みでテスト済みの方法ごと**に制作する。STORESのような審査・有料プランが必要なケースは、その条件を動画冒頭と手順書に明示する。アカウントを持たない状態で本物のUIフローを捏造しない。

## 撮影・編集・アクセシビリティ・SEO/GEO

- **映像:** 1920×1080、MP4（H.264）、30 fps程度、画面キャプチャを基本にする。個人情報や秘密が映っていないか1フレームずつ確認する。
- **文字:** 読みやすい日本語フォント・十分な字幕サイズ。小さいブラウザ文字は拡大する。
- **ブランド:** [MisePortロゴの現行方針](../BRAND.md)、Navy `#0B2F54`、Teal `#0EA5B7`、Coral `#FF7F66`。未承認の候補ロゴを「確定版」と表示しない。
- **音声:** 日本語ナレーション、BGM無しでも内容が伝わるようにする。商用利用可能な音源のみ使用する。
- **字幕・テキスト:** `.vtt`や`.srt`字幕ファイル、動画ページに日本語文字起こし・操作ステップ・バージョン・撮影日・出典・実装制限を添付する。
- **公開先:** 後で公式YouTube等へ公開し、GitHub READMEと商店向け日本語手順書からリンク。**実際のURLが発行されるまで仮URLや再生数を記載しない**。
- **更新:** UIやAPI認証が変わった場合、動画の撮影日・対象バージョンを示し、古い動画を更新または非推奨にする。
