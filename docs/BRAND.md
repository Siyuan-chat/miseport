# MisePort ブランドと画像の公開基準

**更新:** 2026-10-29 JST  
**状態:** 公開用ブランドの出典・権利と現在の適用範囲を区別。

## ブランドの考え方

- 製品名：**MisePort（ミセポート）**
- 日本語の説明：**日本の小さなお店を、AIエージェントへ。**
- 対象：日本の小規模EC事業者、オープンソース開発者、正確な商品データを必要とするAIエージェント。
- 発信：実装済みと計画、架空商品と本物のショップ、固定スナップショットと最新在庫、Custom Connectorと公式Directory承認を明確に分ける。

## 画像素材

ユーザーが提供したオリジナル画像を `assets/original/miseport-logo.png` と `assets/original/miseport-brand-board.png` に保持し、出典・同一性は `assets/original/provenance.json` に記録しています。画像の描画・再構成に必要な**オリジナルSVGや元フォント**が提供されたわけではありません。

独立して作成した旧M字型のブランド案や、レビューが完了していないベクター候補は**公式ロゴとして扱いません**。リリースのソースと配布物に不要な歴史候補ファイルを含めず、必要な場合はGit履歴や権限のある保管先から確認してください。

正式なファビコン・OG画像などは、公開される実ファイルとデザインを確認してから使用します。単に公開Repoに存在するだけでブランド採用や権利を示しません。第三者の商店ロゴや写真は、その商店の**個別の許諾**を確認してから掲載します。

## すでに公開してよい表現

- 日本語README・ライセンス・ソース・架空デモが公開されていること。
- 現行Alphaが、確認できる範囲で読み取り専用API/CSV、商品監査、MCP/RESTを提供すること。
- CIと実証済み機能の範囲を、対応する検証結果の日時とともに示すこと。

## まだ主張してはいけない表現

- 実在商店での導入・売上増加・順位改善がすでに達成されたこと。
- Meta Museに公式採用・公開Directory掲載されていること。
- AIが自動であらゆるMCPを見つけ、商品を推薦すること。
- 商品の価格・在庫・送料がリアルタイムで保証されること。
